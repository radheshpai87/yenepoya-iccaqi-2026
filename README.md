## Overview

The International Conference on Computing, AI, Quantum Intelligence and Future Technologies (ICCAQI 2026) is an international forum organized by the Yenepoya School of Engineering & Technology, Yenepoya (Deemed to be University).

The conference provides a global platform for researchers, academicians, industry professionals, and students to share innovative ideas, research findings, and practical experiences across computing, artificial intelligence, quantum intelligence, and emerging technologies.

---

## Key Highlights

- **8 Interdisciplinary Tracks:** Covering AI/ML, Quantum Intelligence, Big Data, Cyber-Physical Systems, Biomedical AI, and Technology Ethics.
- **Peer-Reviewed Proceedings:** All accepted and presented papers will be considered for publication in reputed peer-reviewed journals with official DOI assignment.
- **Indexing Channels:** Google Scholar, Crossref, MIAR, Ulrichsweb, EBSCO, DeepDyve, Dimensions, and TrendMD.
- **Scopus & Publisher Consideration:** Selected high-impact contributions will be considered for publication in Scopus-indexed Q3/Q4 journals or as book chapters in Scopus-indexed Wiley book series, subject to peer-review and applicable requirements.
- **Flexible Hybrid Delivery:** Authors and delegates may present in-person at the Mangaluru campus or virtually via online technical sessions.

## Getting Started

### Prerequisites
- Node.js 18.17 or later
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/radheshpai87/yenepoya-iccaqi-2026.git

# Navigate to project directory
cd yenepoya-iccaqi-2026

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open `http://localhost:3000` in your web browser to view the application.

### Building for Production

```bash
npm run build
npm run start
```
